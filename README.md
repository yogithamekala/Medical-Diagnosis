Medical Diagnosis Web Application

A machine learning-powered web app for preliminary medical diagnosis. Users can upload their medical data to receive predictions for diseases like diabetes, cancer, pneumonia, and more. The system supports doctor appointment booking and email-based communication.
Built with Flask, HTML, CSS, Bootstrap, and trained ML/DL models.  
Models trained on datasets from Kaggle with up to 99% accuracy.  
Doctor consultation feature via email built-in.
